# ANCESTOR

**A clinical dossier for one body.** A free, offline-first training app: it
decides what to do today from what you actually lifted, then shows you the
working. No account, no cloud, no tracking.

```
app/       the product — four destinations, 88 exercises, 11 lessons, 7 languages
design/    the direction, the system, the artefacts, the roadmap, the case study
site/      the landing page (one file; figures copied from the app)
```

```bash
cd app && python3 -m http.server 8000      # the app
python3 -m http.server 8080                # the repo (app, site and design/ documents)
```

## Verify something

```bash
cd app && npm run verify     # everything below, in one command, exits non-zero on any failure
```

Which is the same as, one at a time:

```bash
cd app && for t in design premium ui run inclusive personas science logic anatomy print; do
  node tests/$t.js
done                                        # 1,488 checks over 10 suites
node tools/keyscan.js                       # no untranslated key reaches a screen
node tools/qa_audit.js                      # structural audit, gated on its own findings
python3 build.py && node tools/smoke_dist.js   # the single file, booted and used
python3 ../site/build.py && python3 ../site/check.py
```

The browser suite is separate because it needs a Chrome binary:
`npm run test:browser` (76 checks, and the only one that measures layout).

## The rules it is held to

- **Ivory paper, charcoal structure, one burnt accent.** Burnt is a signal, not
  decoration: primary action, selection, one data series.
- **Offline by construction.** No CDN, no remote font, no analytics; the app is
  one file and asks for nothing at runtime.
- **No photography.** Every visual is type, rule, or a drawing generated by the
  app's own functions.
- **Free.** No account, no ads, no tiers.

The display face is Barlow Condensed (SIL OFL 1.1), bundled and inlined; the
licence is in `app/fonts/OFL.txt`.
