WHAT THIS REPOSITORY ACTUALLY SHIPS

  assets/anatomy-male-mobile.glb    the mesh itself, 904 KB, meshopt-compressed
  assets/anatomy-map.json           the node/group metadata it carries
  tools/figure-projected.json       DERIVED: the flattened views projected out of
                                    that mesh (silhouette plus one outline per
                                    training group, front and back)
  js/ui/components.js, inside the
  /* <figure-geometry> */ block     DERIVED: the same projection compiled into
                                    drawing coordinates, generated by
                                    tools/build-figure.js. Do not hand-edit; run
                                    `npm run figure` (see app/ARCHITECTURE.md S8).
  release/ancestor.html             the single-file build, which embeds the mesh
                                    base64 and therefore redistributes it — the
                                    in-app credit line travels with it
                                    (i18n key `lab3d.credits`, all seven
                                    languages) because a redistribution without
                                    attribution would breach the licence.

  The projection is a derivative of the mesh, so ShareAlike applies to it too:
  figure-projected.json and the generated figure block are CC BY-SA 4.0 as well.
  That is deliberate and unavoidable — an outline traced from CC BY-SA geometry
  is Adapted Material, not a new drawing.

  Earlier revisions of this notice listed the full-body male and female GLBs,
  the full-body map and the female muscle map by name. Those were the file names
  of the upstream atlas build this repository was cut from; they are not present
  here. The notice is kept as received, with the names above added for this
  repository, rather than rewritten.

CHANGES MADE

  - Extracted only the skeletal muscles, the supporting skeleton, head/hand/
    foot context muscles and connective tissue. Removed the source scene
    hierarchy, materials, text definitions, scripts and textures.
  - Excluded the separately licensed content bundled with Z-Anatomy (brain,
    cranial nerves, inner ear, kidney). None of it appears in these files.
  - Assigned stable muscle IDs (218 regions: 109 muscles, left and right),
    training-group and layer metadata as glTF node extras.
  - Reduced the polygon count to a mobile budget (about 129,000 triangles),
    validated meshes, applied smooth shading, converted Blender Z-up to glTF
    Y-up and exported GLB files.
  - Female variant: an artist-authored deformation of the male geometry
    (about 1.63 m tall) with unverified proportions, plus two illustrative
    breast-context meshes that carry no muscle IDs. It is not independently
    sourced female anatomy.
  - Neither model has been reviewed by an anatomy specialist. Colors shown in
    the app are training estimates, not measured muscle activation.
  - 2026-10-28: derived a flat 2D figure from the mesh. Each of the 26 muscle
    groups was rendered to its own depth buffer from the front and from the
    back, occluded per group, traced with marching squares and simplified
    (Douglas-Peucker, 1.6 px). No anatomical detail was added, removed or
    redrawn by hand: every point in the flat figure comes from the mesh above.
    The process is reproducible with `tools/figure-project.html` and the
    parameters are recorded in app/ARCHITECTURE.md.
